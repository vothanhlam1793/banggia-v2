BangGia v3 — Kế hoạch triển khai

I. Tổng quan

Mục tiêu: Xây dựng lại toàn bộ hệ thống bảng giá trên stack hiện đại. Backend = canonical product server, lấy product code từ KiotViet. Quản lý giá trực tiếp trên Admin Dashboard. Demo cho sếp, sau đó deploy production.

VII. Lộ trình triển khai

1

Backend — Scaffold + DB Models backend

  • Khởi tạo project: Express + Apollo Server 4 + Mongoose
  • Mongoose models: Product, PriceLog, User
  • Kết nối MongoDB, seed admin user
  • GraphQL typeDefs + resolvers cơ bản (CRUD Product)
2

Backend — Business Logic backend

  • KiotViet service: auth token, sync products, search
  • updatePrice mutation: cập nhật giá + tạo PriceLog
  • staleProducts query: tính daysSince + isStale/isWarning
  • Auth: JWT login, middleware bảo vệ mutation admin
3

Frontend — Public App web

  • Next.js scaffold + Tailwind + Apollo Client
  • Trang chủ: search + bảng giá theo group (SSR/ISR)
  • Trang info: liên hệ
  • Deploy dev: port 10200
4

Frontend — Admin App web

  • Login page + JWT auth flow
  • PriceCheck dashboard: filter, sort, màu stale
  • ProductDetail: form cập nhật giá + lịch sử
  • Mapping: search KiotViet + auto-suggest + accept
  • Deploy dev: port 10201
5

Docker + Demo ops

  • Dockerfile cho backend + web + admin
  • docker-compose.yml: backend + mongo + 2 frontend
  • Demo sếp trên local
